去掉导航轨 · 状态栏到底层

轨没了，导航去哪

两件事：状态栏从卡片里提出来，铺满整宽写在画布上（不要背景）； 导航轨整个去掉 —— logo 不要，主题/设置进标题栏右侧的「⋯」， 会话/看板/记忆/代码/终端挪到右侧面板顶部的一条导航栏里。

这份稿子主要比的是右侧那条导航栏怎么排，以及检视器收起时它去哪 —— 后者是个真问题：导航入口不能因为收起面板就没了。

改动清单

  • 状态栏：从主区卡底部提到画布最底部，100% 宽，不占卡片、不要背景。
  • 导航轨整条去掉（56px 宽那一列消失，侧栏成为最左）。
  • logo（π）去掉。
  • 主题切换 + 设置 → 标题栏右侧「⋯」菜单里。
  • 会话 / 看板 / 记忆 / 代码 / 终端 → 右侧面板顶部的一条导航栏。

一 · 层级变化

状态栏从「浮板内部的一条」变成「写在背景上的一条」—— 跟标题栏对称，上下各一条边。

标题栏（画布上） 三张卡浮在画布上 状态栏（画布上，全宽，无背景）

二 · 三个方案

三个方案都遵守上面那五条改动。差的是右侧导航栏的排法， 以及检视器收起时导航去哪（这个每个方案都得回答）。

A · 推荐

只有图标、均匀铺满；检视器收起时导航栏留在右边一条窄轨

导航栏横排在右侧面板顶部，只有图标、不写文字：5 个图标各占一格，均匀铺满 300px 的面板宽度。 检视器收起时，导航栏不跟着消失 —— 它变成右边一条 38px 的窄轨（图标竖排）， 面板内容（Git / Agent）收起来。

三 · 三个方案比

方案认得出吗收起检视器后要维护几种形态收起后右侧占宽
A 只图标 · 收起成窄轨（已选）只能靠悬停变成 38px 竖排窄轨两种38px
B 纯图标 · 收起后搬到标题栏只能靠悬停搬家到标题栏（位置会跳）一种0
C 图标+文字 · 收起成胶囊一眼认得出缩成当前项胶囊两种120px

已选：A（只有图标）

  1. 收起时留一条 38px 窄轨，而不是搬家或者缩成胶囊 —— 入口位置不变（一直在右边），只是从横排变竖排。搬家的代价是「收起之后不知道去哪点」。
  2. 5 个图标各占一格、均匀铺满面板宽度，点按区域大，也不用算间距。
  3. 只留图标，导航栏最矮最干净。代价是认不出 —— 所以每一项都要有 title， 悬停能看到名字。

两种形态（横排 / 竖排窄轨）只差 flex-direction 和尺寸， 同一个组件加一个 compact 属性就能覆盖。

三个需要你确认的：
  1. 「右侧边栏」我理解成现在的检视器（Git / Agent 那块面板）。 如果你指的是别的，这条整个要重画。
  2. 导航栏放在检视器里，意味着「切视图」的入口在右边。 主区在左边，视线要跨过整个窗口。要不要把导航栏也放到主区顶部？
  3. 状态栏不要背景 —— 那它跟画布同色。滚动条、卡片底边都贴着它， 要不要在它上面加一条极淡的分隔线，不然会和卡片粘在一起？

五 · 这一稿不做

项为什么
导航项的内容（看板/记忆/代码/终端到底显示什么）它们现在都是「视图还没接」的占位。这轮只动外壳位置。
快捷键导航没有快捷键，这轮不引入。
状态栏显示什么内容还是那几项（Codelet / session / 模式 / events / Pi 状态），只换位置和背景。
侧栏和检视器的拖拽轨去掉不影响拖拽手柄，它们的定位从「轨右边」改成「窗口左边」。

六 · 怎么算做对了

#标准
1导航轨那一列彻底没有 —— 侧栏贴着窗口左边缘
2状态栏铺满整宽、在最底部、没有背景色（跟画布同色）
3状态栏不再属于任何一张卡片
4logo 没了；主题切换和设置在标题栏「⋯」菜单里，能点
5右侧面板顶部有导航栏，5 项都在，当前项高亮
6点导航项，主区跟着换（现在是占位，也要能切）
7收起检视器后导航入口还在（按选的方案）
8拖拽手柄位置跟着轨消失调整，能正常拖
9亮暗两套主题下，状态栏跟画布、卡片跟画布都分得清
