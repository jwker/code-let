我的建议

C 最稳妥：品牌只出现一次，轨道和顶栏都干净，而且不受 macOS 红绿灯位置影响（红绿灯只占 0–70px，都在顶栏那条带里）。实现上就是现在侧栏标题前的文件夹图标换成 π 方块，一个 class 的事。

A 最省事，但 π 悬在红绿灯正下方 10px 处，视觉上会跟红绿灯抢那块角落，窄窗口下更明显。

实现「打通」本身只要一句 CSS：顶栏底边线改成 .shell-title::after { left: var(--rail-w) }，轨道右边的竖线从 top: 0 改成 top: var(--titlebar-h)。上面 5 个方案都要这步。
