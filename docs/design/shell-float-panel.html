外壳重排 · 一整块浮板

把侧栏、主区、检视器并成一块浮板

这份稿只做一件事：把外壳的层级关系改掉。 导航轨和标题栏是底槽（100% 高 / 100% 宽，连成一个 L 形）， 它们之外的区域是一整块浮板，浮板内部再分成侧栏、主对话区、右侧检视器三个板块。 标签栏搬进标题栏，成为标题栏的中间一段。

现在和之后的差别是：侧栏、主区、检视器是三个各自带底色、带圆角的独立浮板 （三档底色只差 4–5/255，靠竖线分界）；改完是一块浮板里的三个板块。

一 · Z 空间层级

三层，从下往上：窗口背景 → 大浮板 → 轨和标题栏的内容（直接写在背景上）。

轨
100% 标题栏 · 100% 宽 一整块浮板（内部三块） 轨

轨和标题栏是背景色（--canvas），浮板是面板色（--surface）， 浮板的左上角是圆的 —— 背景从那个角透出来，浮板就「浮」在背景上。

已经定死的（不用再比）

  • 轨 100% 高、标题栏 100% 宽，两者连成一个 L 形，都用背景色。
  • 标签栏进标题栏，作为标题栏的中间一段；左边是按钮板块，右边是按钮板块。
  • 浮板内部三块：侧栏、主对话区、右侧检视器。
  • 标签栏不再单独占一行 —— 主区多出 36px。

二 · 三个方案

三个方案都遵守上面这四条。差的是浮板内部三块怎么分，以及状态栏去哪。

A · 推荐

一块底色 + 竖线分栏，状态栏在浮板内部

浮板整块都是 --surface（白），三块之间只用竖线分。 状态栏变成浮板底部的一条（只占主区+检视器那两段，跟现在一样不铺到侧栏下面）。

三 · 三个方案放在一起比

方案「一整块」的感觉主区可用高度跟现在差多少改动面
A 统一底色 · 状态栏在浮板内强比现在少 36px（标签栏并进标题栏）中中
B 三档底色 · 状态栏在浮板内弱比现在少 36px小小
C 统一底色 · 状态栏进标题栏最强比现在少 16px大大

推荐：A —— 一块底色 + 竖线分栏，状态栏在浮板内部

  1. 浮板内部统一成一块底色。三档底色只差 4–5/255，正常的屏上根本看不出来 —— 保留它只是「看着有区别」而实际没有。去掉之后浮板才真的是一整块。
  2. 状态栏留在浮板内部。它那串信息（session id、模式、事件数、Pi 状态）是开发者向的， 但它占的位置是实打实的 —— 放标题栏右侧要跟标签抢地盘（方案 C 的代价）。 浮板底部留 20px，换来的是标题栏干净、标签板块宽裕。
  3. 标签板块对齐主对话区。标签正好排在它下面那块内容的正上方， 视线从标签移到对话是直的。

如果你更看重「跟现在的观感差别小」，选 B —— 它就是 A 的保守版：结构一样，只是浮板里面还留着三档底色。

还有三处这张稿里先定了、你可以推翻的。
  1. 浮板跟轨、标题栏之间不留缝。现在是紧贴的（侧栏紧挨着轨）， 浮板只有左上角是圆的、背景从角上透出来。要不要四周留 8px 的缝、整块浮起来？
  2. 浮板只有一个圆角（左上角）。现在的检视器右上角、侧栏右下角都是直角， 改成一整块之后这些角怎么处理要定。
  3. 侧栏收起时：浮板的左边界移到轨的右边，左上角跟着移 —— 这套逻辑今天就有（D16 记的「延后 180ms 交接」），改造成本不大。

四 · 要动的东西

host/renderer/src/styles/global.css .shell{ /* 轨 100% 高、标题栏 100% 宽 → 两者是背景色，连成 L 形 */ grid-template-columns: var(--rail-w) minmax(0, 1fr); grid-template-rows: var(--titlebar-h) minmax(0, 1fr); grid-template-areas:'chrome chrome' 'rail panel'; } /* 浮板：一整块，三块内部用竖线分 */ .shell-panel{ grid-area:panel; background:var(--surface); border-top-left-radius:calc(var(--panel-radius) - 1px); overflow:hidden; display:grid; grid-template-columns:var(--side-w) minmax(0,1fr) var(--insp-w); grid-template-rows:minmax(0,1fr) auto; } /* 标题栏：四段 —— 轨（红绿灯）· 左按钮 · 标签 · 右按钮 */ .shell-title{ grid-area:chrome; display:grid; grid-template-columns:var(--rail-w) var(--side-w) minmax(0,1fr) var(--insp-w); } /* 标签栏：从独立的一行搬进标题栏的第三段 */ .shell-tabs{grid-column:3;display:flex;align-items:stretch;overflow:hidden} /* 三块面板不再是各自独立的浮板 —— 去掉各自的底色和圆角 */

标签栏从 .shell-tabs（独立一行）变成标题栏里的一个 grid 段； ProjectSwitcher 已经删了，侧栏那块不用动。 .side-panel / .shell-main / .shell-insp 三者的 底色、圆角、边界线都要收进 .shell-panel 里统一管。

五 · 这一稿不做

项为什么
浮板四周留缝（真正「浮」起来）稿里先按紧贴画 —— 留缝会让侧栏收放时多一层位移动画，复杂度上一个台阶。先看紧贴的效果。
浮板整体拖动 / 调整大小现在是两栏各自拖。改成一块之后拖哪一条边要重新定义。
检视器改成抽屉另一件事（主区宽度问题）。
动终端 / HTML 两档排版普通模式优先（D14）。

六 · 怎么算做对了

#标准
1轨从窗口顶到底，标题栏从窗口左到右，两者连成一个 L，中间没有缝
2轨和标题栏之外是一整块浮板，只有一个左上角是圆的
3浮板内部能看出三块（侧栏 / 主区 / 检视器），但它们是同一块板上的分区
4标签栏在标题栏里，左边是侧栏开关，右边是检视器开关
5标签板块的左边缘跟主对话区的左边缘对齐
6侧栏收起时，浮板左边界右移到轨边，左上角跟着移，全程不跳
7标签栏不再单独占一行 —— 主区比现在高 36px
8亮暗两套主题下，浮板跟底槽的边界、竖线、圆角都读得清
