右侧面板 · 常驻还是切换

右侧面板里到底放什么、怎么放

现在的做法是：导航项（看板/记忆/代码/终端）占满整块面板，没选时显示 Git + Agent。 问题是这两组互斥 —— 点开看板，Git 和 Agent 就没了。

这份稿子比的是「常驻面板（Git/Agent）和导航视图能不能同时看」。 三个方案，都能收成 38px 窄轨。

现在的组件清单

  • 导航视图（点了才出现）：看板 · 记忆 · 代码 · 终端 —— 都还是「视图还没接」的占位。
  • 常驻面板（一直有）：Git · Agent —— 也都是「面板还没接」的占位。
  • 共同点：六个都还没有真内容。所以现在定的是结构，不是具体组件。

A 和 B 都把右侧分成上下两栏（上面切换、下面常驻）；C 保持「一次只显示一个」， 把 Git / Agent 也变成导航项。

二 · 三个方案比

方案Git/Agent 一直看得见吗视图能用满面板吗结构复杂度图标宽度
A 上下两栏（固定比例）看得见（在下半）只能占上半简单75px
B 上下两栏（可拖）看得见（可调大小）能拉到很大多一根拖拽线75px
C 全切换（6 个导航项）看不见用满整块最简单50px

推荐：A（上下两栏，固定比例）

  1. 两组同时看得见。看代码的时候 Git 状态还在下面 —— 这是分栏唯一的价值。
  2. 不用拖拽。窗口里已经有两根拖拽线（侧栏、检视器），再加一根容易拖错。 固定比例（比如上 6 下 4）够用。
  3. 导航栏还是 4 个图标，每个 75px，比 C 的 50px 宽得多。

如果以后发现「看板 / 代码」需要很大空间，再升级到 B（加拖拽）或者 「点导航时临时占满整块、再点一次回到分栏」。

三个要你定的：
  1. 上半块没选导航项时显示什么？空白 + 一句「从上面的图标里选一个」？还是默认选中第一个（看板）？
  2. 上下比例：我倾向 6 : 4（上面给视图、下面给常驻）。Git/Agent 两张卡片加起来大概需要 200px， 300px 高的下半够。
  3. 常驻面板能不能折叠？如果某天你只想看代码、不关心 Git，下半块能不能点一下收起来 —— 那就是「上下两栏 + 下半可折叠」。
