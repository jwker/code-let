# 窗口分成两半：左边对话和设置，右边一个功能区

应用主体改成横向两半。左半边是完整的应用 —— 标题栏、窄轨、唯一的一列内容（当前 agent 的对话，或者
占满整列的项目设置）、状态栏；右半边是一条从窗口顶边贯到底边的**右栏**，同一时刻只放一个**功能区**：
代码、文档、浏览器。右栏可以收起，收起后左半边吃满窗口。

区域 5 和区域 6 这两个位置退场。原来是「窄轨 + 可选区域 5 + 必填区域 6」的三段式，现在只剩
「左列 + 右栏」两段：文件树、文档树、代码预览、文档正文、浏览器全部搬进右栏的功能区。

## 为什么要动布局

浏览器的页面是原生 `WebContentsView`，永远画在 DOM 之上。原来的对策是浮层跟浏览器矩形重叠时把
原生视图收起来（`shell/overlay.ts` + `shell/useOverlay.ts`），代价是页面闪一下，而且「收起原生视图」
这件事本身就意味着用户正在看的东西会消失。

布局改完之后，浮层的矩形碰不到原生视图：菜单只在左列里弹，对话框在左列居中。问题从「z 序对抗」
变成「几何隔离」，`useOverlay` 从常态手段降级成兜底（贴边菜单仍可能越界时用）。

## Considered Options

- **维持三段式，继续用 `useOverlay` 收视图**：不做改动，但每次弹菜单都闪，且对话框盖不住原生视图
  这件事没有解。
- **把浏览器改成 iframe**：浮层问题消失，但原型预览会丢掉 `browser_screenshot`、标注注入和真实文档
  地址 —— 0002 已经否掉了这条路。
- **采用：左右两半，右栏放功能区**：几何上分开，原生视图的矩形里永远不需要放 DOM 浮层。

## 右栏的形状

- 同一时刻只显示一个功能区，没有标签条。空态（展开了但没东西）居中给三个按钮：浏览器、代码、文档。
- 有内容时，右栏顶栏左边写当前在看什么（页面标题 / 文件名 / 文档名），右边是**功能切换器**：
  一颗图标加名字，点开是三项下拉，当前项打勾。右边紧挨着收起按钮。
- 右栏宽度下限 380、上限 900，**默认是窗口宽度的一半**，可以拖；收起展开的开关在左半边标题栏的最右侧。
- 浏览器功能区内部保留自己的页面标签行（一个浏览器可以有多个页面），代码和文档功能区的「多个」
  由各自左侧的树承担。

## 状态记在哪

`open` 和 `kind` 跟项目标签走：每个项目标签各记一份，切走再切回来还是原来的样子，和原来记 `pane`
一样落在 `ProjectTabInfo` 上。**宽度不按标签记**，一份全局的界面偏好放在渲染进程的 localStorage 里
—— 窗口宽度是窗口的事，不是项目的事。

## agent 怎么主动切换

复用现有的浏览器活动通道（`BrowserState.agent` + `shell/browserFocus.ts`）：产品 agent 写原型时
主进程换一份新的活动记录，渲染进程认出「换了一份」就展开右栏、把功能区切到浏览器。用户手动切换走
同一入口（`openRightPanel(kind)`），不写活动记录，所以不会互相触发。

右栏里浏览器的宿主跟随左列：左列是带 `preview` 能力的 agent 时用 `agent:<id>`，否则用 `project`。

浏览器的两个标签池（项目级和 agent 级）合并成一份标签表，每个标签记宿主。合并之后「agent 碰不到别的
宿主的标签」这条边界从物理隔离（分池）变成代码过滤（工具入口按宿主过滤），这是这次合并的主要风险，
测试要专门盯。

## Consequences

- `ProjectTabInfo.pane` 的取值从 `code | docs | browser | settings | agent` 收窄成 `agent | settings`，
  新增 `rightPanel: { open, kind }`。磁盘上的旧标签要迁移：旧 `pane` 是代码/文档/浏览器的，改成
  `pane: 'agent'` 加对应的 `rightPanel.kind`。
- `PANE_LAYOUT`、`paneLayoutFor`、`ZONE5_MIN/MAX`、`AgentCapabilities.zone5` 全部删除。类型能力只剩
  `preview` 和 `autoArchive` 两条。
- e2e 里所有「区域 5 / 区域 6」的说法和断言都要改（`shell.spec.ts`、`newconv.spec.ts`、`git.spec.ts`、
  `annotation.spec.ts`、`productAgentBrowser.spec.ts`）。
- `zone5-*` / `zone6-*` 这批 CSS 类名和 `FileTree` 等组件内部的选择器保留原样一段时间：它们是搬进
  右栏的组件内部样式，跟着组件改比一次性重命名安全。新代码不再产生这两个词。
- 右栏开成 380px 时，代码功能区的「树 + 代码」两列会很挤。默认宽度按窗口的一半算，树在窄的时候收固定宽。
- 项目设置（窄轨底部，占左列）和应用设置（标题栏齿轮，独立窗口）仍是两样东西，这次不动它们的分工。
