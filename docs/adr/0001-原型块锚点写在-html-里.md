# 原型块的锚点由 agent 写进 HTML

产品 agent 生成和修改 HTML 原型时，给每个可被指代的块写上 `data-block="<块号>"`；Codelet 只读这个属性、
渲染角标，不自己扫 DOM 分配号。理由：「用户说的 3 号」要变成「文件里的哪一段」，只有文件里自带锚点才能
精确命中。运行时扫页面只能给出一串选择器，而 agent 没有浏览器，只能靠数结构去猜，改错一块的代价是重写整段。

## Considered Options

- **运行时扫 DOM 自动编号**：零维护，任意 HTML 都能用。但 agent 手里只有选择器和文字，一次结构重写之后
  号也全失效，与「精确修改」的目标相悖。
- **混合**（实际采用）：以文件锚点为准；整页一个锚点都没有时退化成临时号（`T1`），并在下一轮由 agent
  补上锚点、转正成块号。

## Consequences

- 产品 agent 的提示词必须带上四条规矩：保住已有的号、不重排、不复用、找不到那块就明说而不许猜。
  违反的后果是号还在、指向已经变了，而用户从画面上看不出来。
- 原型 HTML 里会多出一批 `data-block` 属性。这是有意的，不是噪音，不要当垃圾清掉。
- 块号只在文件内唯一，跨文件靠「文件 + 块号」两段键区分。第一版只有单页，键的形状已经留好。
